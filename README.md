## 🚀 Arquitetura & Componentes

O projeto foi construído sobre o **Next.js 15 (App Router)** com exportação estática (`output: 'export'`) e estilização personalizada com estética terminal e cyberpunk glassmorphism:

- **Wire Terrain 3D:** Simulação retro-futurista de malha topográfica 3D em tempo real no topo da página.
- **Terminal Hero (Typewriter):** Apresentação interativa com efeito typewriter dinâmico e status do sistema.
- **Bio Section & Code Editor:** Foto de perfil em alta definição integrada a um editor de código interativo com abas de bio, experiência técnica e IA.
- **Smooth Scroll Slider:** Galeria interativa de projetos com física de arrasto, inércia suave (`requestAnimationFrame`) e responsividade widescreen.
- **Stacks & Ecossistema:** Carrossel infinito (marquee) com as tecnologias centrais categorizadas em Backend, Frontend/Mobile e IA Generativa para mínima carga cognitiva.
- **Fibre Arc Footer:** Rodapé interativo com feixe de fibra óptica e partículas energéticas reativas ao cursor.

## 💻 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18+ recomendada)
- [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/vitorlopes-coder/portfolio.git

# 2. Acesse a pasta do projeto
cd portfolio

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.

### Build de Produção

```bash
npm run build
```

Os arquivos estáticos otimizados serão gerados na pasta `out/`.
